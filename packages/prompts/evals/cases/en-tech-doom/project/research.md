# Research: why Doom runs everywhere

## Key facts

- Doom was released by id Software in December 1993 — https://en.wikipedia.org/wiki/Doom_(1993_video_game)
- id Software was based in Mesquite, Texas — https://en.wikipedia.org/wiki/Id_Software
- The engine uses 2D sectors with floor/ceiling heights (no room above room, no slopes) — https://doomwiki.org/wiki/Doom_rendering_engine
- The source code was released in December 1997 — https://en.wikipedia.org/wiki/Doom_engine

## Timeline

- 1993-12-10: Doom released as shareware — https://en.wikipedia.org/wiki/Doom_(1993_video_game)
- 1997-12-23: source code released — https://en.wikipedia.org/wiki/Doom_engine
- 1999: source re-released under the GPL — https://en.wikipedia.org/wiki/Doom_engine

## People & entities

- John Carmack, lead programmer of the engine — https://en.wikipedia.org/wiki/John_Carmack
- id Software, developer and publisher — https://en.wikipedia.org/wiki/Id_Software
